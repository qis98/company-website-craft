# Company Website Craft

通用的网站生成与优化 Skill，适用于公司官网、产品展示站及公开内容/资料索引站。

## 能做什么

- 从需求与素材整理网站结构、视觉和页面模板
- 固定导航、筛选与表头，下拉、联动筛选、排序和分页
- 首页轮播、左右点击、鼠标拖动、触摸滑动和自动播放控制
- 响应式布局、产品/文章详情、统一页脚
- 静态正文、基础 SEO、404 和本地验证

这是一套生成工作流与规范，不是现成的网站代码或自动部署服务。品牌、配色、栏目、数据和组件行为按项目配置。

## 使用

将本仓库内容放在 Codex 的 `~/.codex/skills/company-website-craft/` 目录，再在对话中调用：

> 使用 $company-website-craft，根据我提供的品牌、产品和图片生成一个产品介绍网站。包含产品筛选、详情页和联系方式，先完成本地预览，暂不上线。

也可以用于现有项目的局部优化。9篇/页、3列卡片等为可调整默认值，不是所有网站的强制要求。

本仓库仅含通用规则，不包含任何行业项目的专属配置、源码、凭据或客户资料。
