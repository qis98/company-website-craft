# 项目简报

从需求和现有资料提取配置，这是内部工作记录，不是逐项问卷，不渲染到网站。

| 配置 | 要决定的内容 |
|---|---|
| 类型与受众 | 官网、产品展示、内容索引或混合；访客与主要任务 |
| 品牌与语言 | 名称、Logo、favicon、颜色、语气、语言、已有认可设计 |
| 主要动作 | 查看产品、筛选配置、阅读、下载或联系 |
| 页面与内容 | 栏目、数据来源、真实图片、哪些内容不可上线 |
| 列表模式 | 卡片或表格、分类、联动筛选、关键词、排序、页容量、状态保留 |
| 固定元素 | 导航、筛选、表头是否固定；移动端如何折叠 |
| 首页媒体 | 单图或轮播；自动时长、边缘点击、拖动、指示器与暂停 |
| 页脚与联系 | 真实联系、社交账号、二维码资产、版权、适用备案与隐私 |
| 技术与发布 | 框架、存储、构建、域名、静态/动态、预览、当前授权范围 |

## 缺省策略

- 只问会阻断结果的缺项，其余以合理假设继续；事实和联系方式不能靠假设编造。
- 内容少则减少模块，不用假统计、示例文章撑满页面。素材未齐可交付明确缺项的本地原型。
- 颜色、首页结构和卡片形式由品牌与内容决定，通用数值不成为每个站的视觉模板。
- 批准的项目决策写入该项目 DESIGN.md 或既有规范；临时状态、待办、发布批次放项目记录，不写进通用 Skill。
