# 通用布局与交互规范

仅在需要该组件时使用。数值是起始默认值，用户当前要求与既有设计优先。

## 1. 页面尺度与信息密度

- 桌面容器可从 1120–1280px、长文正文 680–800px 起步，左右对称留白；宽参数表与目录可合理扩大，不为统一而挤窄。
- 卡片通常桌面3列、平板2列、手机1列；按内容最小可读宽度设断点，间距可从24–32px起步。目录行随内容自然增高，不固定大行高。
- 调整容器、字号、图片与间距，不用整页 zoom/transform 假装响应式；不用满屏标题和过高 banner 掩盖内容不足。
- 首页首屏优先呈现品牌、核心信息、行动和下一段入口，同时留呼吸空间。不要求小屏把所有模块塞满一屏；不得截断信息或压成微小文字。
- 左右区域共享网格与对齐线。索引面板确需等高时可限高内部滚动；移动端恢复自然高度或提供清楚可触摸的滚动区，不困住页面滚动、不隐藏所有滚动提示。
- 不强制每站同一字号；用少量层级建立清楚的标题、正文、次要信息关系，确保对比度和中文换行。

## 2. 导航、固定筛选与表头

- 全局导航可 sticky。透明到实色/滚动变色只在背景需要时使用，两个状态均可读，不因滚动发生高度跳变。
- 长目录可将分类、筛选和必要表头固定在导航下，不给所有标题都加 sticky。
- 使用共同高度/偏移变量，表头接在筛选下；锚点设 scroll-margin-top。检查短父容器、overflow祖先和层叠上下文是否使固定失效。
- 表头与列表共享列网格、列间距和左右边距。描述列按信息量分配，不机械等宽；两侧留白平衡。
- 结果数量与清除筛选优先放分类行右侧，窄屏换行；不为一个数量新增标题横条。具体项目已认可的位置优先。
- 手机上缩减或折叠次要条件，必要时只固定精简操作条；保证结果有足够可用高度。验证菜单展开、键盘焦点、首尾条目不被遮挡。

## 3. 下拉、筛选、排序与状态

- 简单单选优先原生 select；复杂自定义下拉仅用于确有必要的搜索、多选或分组。提供名称、当前值、展开状态、键盘与触屏操作。
- 下拉贴近触发器、宽度适配内容，靠边时调整展开方向，不被父容器或固定栏裁切。区分悬停、选中、焦点；Escape/外部点击关闭，单选选择后关闭。
- 导航 hover 菜单连接触发区与菜单区，鼠标不因缝隙掉出；一级导航点击按实际用途跳转。移动端不依赖 hover。
- 关联字段同行对齐、统一间距、宽度合理，窄屏自然换行，不压成小控件。
- 依赖筛选先选上级再选下级。未选上级时禁用/隐藏下级并提供必要条件提示；切换上级清理不适用旧值。
- 功能名称用跨品牌可理解的能力词；专属型号名称放详情，确有独特意义才作为选项。匹配基于真实数据。
- 显示真实匹配数量；清除后回第一页。排序必须真能操作，明确由新到旧/由旧到新，同值排序稳定。
- 筛选、关键词和排序变化回第一页。目录返回时优先保留筛选、页码与位置，可用 URL 查询参数结合历史状态；不增加无必要跟踪。
- 空结果给简洁恢复操作；没有可用状态的控制禁用，不展示装饰性假按钮。

## 4. 列表、文章与分页

- 文章网格默认每页9篇，适合桌面3×3，可根据内容配置；超过容量才显示分页。
- 提供上一页、页码、下一页，当前页与首尾禁用状态清楚；多页用省略号，手机不溢出。默认不强加无限滚动。
- 切页定位列表开头并管理焦点。可分享分页优先真实URL；客户端分页仍要提供完整可抓取内容入口。
- 从真实数据推导页数，每篇不重复、不漏项；数据或筛选变化后页码限制在有效范围。无效分页URL有明确行为，不冒充无关详情。
- 图片统一显示框但不误裁技术主体，Logo/图表可 contain；标题自然换行，摘要不重复标题，只保留有用元信息。不默认加封面序号。
- 不同文章优先使用不同且切题的封面，确有意义的系列共用视觉可保留。
- 详情用共享模板统一标题、目录、正文、图片、引用；标题层级连续。图片尺寸按信息量决定，不默认占满阅读区域；宽表格可横向滚动。

## 5. 首页轮播与品牌循环条

- 单图能讲清就不加轮播；多个主题才启用，每张均有真实内容和有效链接。
- 标题、描述、链接采用稳定网格，行动位置跨页对齐；图片比例与区域尺寸稳定，不因加载或文字长短跳动。
- 自动轮播可从6–8秒起步；手动操作后重新计时，悬停/焦点进入/拖动时暂停，页面不可见时暂停。减少动态效果偏好下关闭自动播放及持续滚动。
- 持续自动移动提供可访问的暂停/继续手段，样式可克制。用户不要可见按钮时提供清楚可达的替代控制，不能剥夺键盘用户控制。
- 可点击左右边缘翻页；不显示箭头时可用轻微渐变/磨砂作提示，保持文字可读。边缘区不覆盖正文链接，具可访问名称和焦点提示。
- 鼠标左键拖动与触摸滑动作为辅助，设阈值区分点击/拖动，拖动后不误触链接；触屏保留纵向滚动。普通单击图片是否跳转需有明确约定。
- 动画方向匹配操作，首尾循环不闪白或跳帧。指示器如启用须可点击且显示当前项；只有一张时隐藏翻页控制。
- 品牌循环条用真实Logo；副本对辅助技术隐藏，不形成重复焦点/ID；“更多品牌”使用真实链接。悬停/焦点暂停，持续移动提供停止手段，不以无依据排名标注“最知名”。

## 6. 页脚与联系

- 正常页面及404共用页脚；短页合理落底，不悬浮盖住正文。结束间隔清楚且克制，风格与全站一致。
- 根据实际内容包含品牌、有效简介、主要导航、联系方式和版权。列数按信息量决定，手机堆叠/折叠；不重复整个网站目录或塞入长免责声明。
- 电话 tel:、邮箱 mailto:，社交账号清晰可复制。二维码仅在提供真实资产且要求使用时加入，保留说明及替代文字联系。
- 版权主体、年份、隐私/条款按真实情况填写。面向中国大陆且适用时放真实ICP号与工信部链接；公安备案按实际信息和官方要求展示，不能硬编码通用示例。
- 缺失资料留内部待办；本地原型确需占位时明确标识，生产前补全或省略不适用项。不能上传假号码、示例备案。
- 外链新窗口策略统一，需要时处理安全属性。不强制每条链接增加箭头，图标只在有用时出现。

## 7. 验收

- 桌面/平板/手机检查容器、换行、卡片、页脚、横向溢出。
- 滚动检查导航/筛选/表头固定、锚点遮挡、下拉可见与剩余视口。
- 筛选检查依赖切换、清除、空结果、正倒序及返回保留；分页检查容量边界、首尾、无重复漏项与焦点。
- 轮播检查自动切换、暂停、左右翻页、拖动/链接冲突、首尾循环、触屏及减少动态效果。
- 检查初始HTML正文、真实链接、元信息、sitemap、草稿隔离与404，执行相关构建和校验；只声明实际验证过的结果。
